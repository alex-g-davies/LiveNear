**Emne:** Forespørsel om samtykke til begrenset, ikke-kommersiell innsamling av bruktbilannonser

Hei,

Jeg heter [navn] og flytter til Norge [måned/år]. Jeg bygger et lite,
ikke-kommersielt verktøy for meg selv og noen venner som også flytter hit.
Verktøyet sammenligner totalkostnaden ved å eie en bil over 1–4 år (kjøp ny,
leasing, brukt 1–3 år, brukt 5+ år), med usikkerhetsbånd og kildehenvisning
for hvert tall.

Til dette trenger jeg et ukentlig øyeblikksbilde av bruktbilannonser for et
lite utvalg modeller (i første omgang [ca. 5–7 modeller, 2019–2024]):
prisantydning, kilometerstand, årsmodell, variant, selgertype og om annonsen
fortsatt er aktiv. Jeg har lest robots.txt og brukervilkårene (punkt 6) og
har derfor **ikke** satt opp noen automatisert innsamling. I dag registrerer
jeg annonser manuelt.

Jeg ber om skriftlig samtykke til én av disse løsningene:

1. En begrenset, ukentlig automatisert innsamling av søkesidene for de
   nevnte modellene, med lav frekvens (én kjøring per uke, under
   [200] sideoppslag), tydelig User-Agent med kontaktinformasjon, og kun
   lagring av feltene over. Ingen bilder, ingen kontaktinformasjon til
   selgere, ingen videreformidling av data.
2. Tilgang til et eventuelt åpent API eller datasett for ikke-kommersiell
   bruk, dersom dere har eller planlegger dette (API-siden nevner et ønske om
   åpne API-er).

Dataene brukes kun til modellering av verdifall og vises aggregert i
verktøyet (kohortverdier med intervall), ikke som enkeltannonser utover det
som allerede er offentlig. Kildekoden er åpen (AGPL) og inneholder ingen
innsamlingskode for FINN før et samtykke foreligger.

Si gjerne fra om dere trenger mer informasjon, eller om det finnes en
betalt lisens som passer for privat bruk.

Vennlig hilsen
[navn, e-post, telefon]

**Subject:** Request for consent to limited, non-commercial collection of used-car listings

Hello,

My name is [name] and I am moving to Norway in [month/year]. I am building
a small non-commercial tool for myself and a few friends who are also
relocating. It compares the total cost of owning a car over 1–4 years (buy
new, lease, used 1–3 years, used 5+ years) with uncertainty bands and a
source for every number.

For this I need a weekly snapshot of used-car listings for a small set of
models (initially [about 5–7 models, 2019–2024]): asking price, mileage,
model year, variant, seller type and whether the listing is still active. I
have read robots.txt and the user terms (section 6) and have therefore
**not** set up any automated collection; today I record listings by hand.

I am asking for written consent to one of the following:

1. A limited weekly automated collection of the search pages for those
   models: one run per week, under [200] page requests, a clear User-Agent
   with contact details, storing only the fields above. No images, no seller
   contact details, no redistribution of the data.
2. Access to any open API or dataset for non-commercial use, if one exists
   or is planned (the API page mentions a wish to offer open APIs).

The data is used only to model depreciation and is shown aggregated in the
tool (cohort values with intervals), not as individual listings beyond what
is already public. The source code is open (AGPL) and contains no FINN
collection code until consent exists.

Please let me know if you need more information, or if a paid licence
suitable for private use is available.

Kind regards
[name, e-mail, phone]
